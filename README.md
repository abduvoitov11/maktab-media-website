# 🎬 MediaMaktab — Maktab Media Koordinatori Veb-Sayti

Ushbu veb-sayt **Vercel** va **Netlify** platformalariga 100% moslashtirilgan bo'lib, **iOS 28 Liquid Glass** uslubi va **to'liq ekranli kinematik fon rasmlari** bilan yaratilgan.

---

## ⚡ Vercel'ga 1 daqiqada joylash (3 xil usul):

### 1-usul: Terminal orqali (Eng tezkori):
Ushbu papka ichida turib quyidagi buyruqni ishga tushiring:
```bash
cd /home/torabek/Desktop/maktab-media-website
npx vercel
```
*Vercel sizdan login qilishni so'raydi (email yoki GitHub bilan), so'ngra bir necha soniyada bepul `https://maktab-media-website.vercel.app` manzilini beradi!*

Keyingi safar production'ga chiqarish uchun:
```bash
npx vercel --prod
```

### 2-usul: GitHub orqali (Avtomatik yangilanadigan):
1. [github.com](https://github.com) da yangi repo oching (masalan: `maktab-media-website`).
2. Terminalda quyidagilarni bajaring:
   ```bash
   cd /home/torabek/Desktop/maktab-media-website
   git remote add origin https://github.com/<GITHUB-LOGININGIZ>/maktab-media-website.git
   git branch -M main
   git push -u origin main
   ```
3. [vercel.com/new](https://vercel.com/new) ga kiring va GitHub omboringizni tanlang. «Deploy» tugmasini bosing — tayyor!

### 3-usul: Netlify (Drag & Drop zaxira varianti):
1. **[app.netlify.com/drop](https://app.netlify.com/drop)** ga kiring.
2. Ish stolidagi **`maktab-media-website.zip`** faylini oynaga tashlang.
